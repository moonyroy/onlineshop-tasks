# خروجی نهایی مشتری‌ها

این فایل نسخهٔ خلاصه و قابل‌ارائهٔ نتیجهٔ پروژه است. هر ردیف مربوط به یک مشتریه و فقط ستون‌هایی رو نگه داشتیم که برای فهم وضعیت و تصمیم پیگیری لازم‌اند. فایل **۴٬۳۷۲ مشتری یکتا و ۹ ستون** داره.

برای خوندنش اول وضعیت و گروه مشتری رو ببین، بعد سطح خطر و اولویت رو و در آخر اقدام پیشنهادی رو بخون.

| ستون | توضیح ساده |
|---|---|
| `CustomerID` | شناسهٔ مشتریه. هر مشتری فقط یک ردیف داره. |
| `customer_status` | می‌گه مشتری فعاله، غیر فعاله، تازه‌وارده یا خرید مثبت کافی برای بررسی نداره. |
| `segment_name` | گروه رفتاری مشتریه، یعنی معمولاً چه‌جوری خرید کرده. شماره یا اسم گروه، درجهٔ خطر نیست. |
| `risk_level` | سطح خطر برآوردشدهٔ ریزشه. برای مشتری غیر فعال یا بدون سابقه، وضعیت جدا نوشته شده. |
| `risk_probability` | احتمال مدل برای توقف یا افت خرید طبق تعریف پروژه در افق ۱۰۰روزه است. مثلاً ۰٫۶ یعنی ۶۰ درصد. این عدد تضمین اتفاق‌افتادن ریزش نیست. |
| `priority_level` | می‌گه پیگیری مشتری چه اولویتی داره، مثل پایش، پیگیری معمولی یا پیگیری ویژه. برای غیر فعال‌ها مسیر بازگشت جدا داریم. |
| `risk_reason` | چند نشانهٔ رفتاری مثل فاصله از آخرین خرید و تعداد فاکتورها رو خلاصه می‌کنه. علت قطعی ریزش یا توضیح دقیق محاسبهٔ احتمال نیست. |
| `suggested_action` | پیشنهاد اولیه برای پیگیریه. تیم بازاریابی باید هزینه، امکان اجرا و شرایط تماس رو بررسی کنه. |
| `recommended_product_name` | محصول مرتبطی که بر اساس قواعد خرید پیشنهاد شده. اگر خالیه، پیشنهاد واجد شرایط پیدا نکردیم یا سابقه کافی نبوده. |

## چند نکته برای برداشت درست

- احتمال خالی یعنی برای اون مشتری امتیاز محاسبه نشده، نه اینکه خطرش صفره.
- سطح خطر با اولویت یکی نیست. برای اولویت، ارزش احتمالی خرید آینده هم در کنار خطر در نظر گرفته شده.
- پنج سطح خطر بازه‌های ثابت دارن و لازم نیست همهٔ سطح‌ها عضو داشته باشن.
- تاریخ بررسی **۹ دسامبر ۲۰۱۱** است. مدل تاریخی به این تاریخ منتقل شده و رفتار بعد از پایان فایل در دسترس نیست، پس ارزیابی آیندهٔ این فهرست رو نداریم.
- تازه‌واردها سابقهٔ کوتاه‌تری دارن و نتیجه‌شون باید با احتیاط بیشتری خونده بشه. برآورد ارزش آینده هم محدودیت‌های مدل خرید رو داره.
- اقدام‌ها پیشنهاد آموزشی‌اند. هنوز با اجرای کمپین ثابت نکردیم که باعث حفظ مشتری می‌شن.

نسخهٔ کامل با همهٔ ویژگی‌ها، برآوردها و هشدارهای هر مشتری در [خروجی تسک ۰۰۳](../task-003/outputs/customers_marketing_final.csv) حفظ شده. برای بررسی فنی یا تصمیم عملی، جزئیات و هشدارهای اون فایل هم باید دیده بشن.
